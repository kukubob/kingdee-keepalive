# 金蝶云星空 HTML5 保持在线

一个 Tampermonkey（油猴）脚本：按分钟显示金蝶距离闲置退出的剩余时间，在闲置满一分钟时调用原生“继续在线”事件。无需刷新业务页面，支持暂停或恢复。

## 安装

1. 浏览器安装并启用 Tampermonkey。
2. **[点击安装脚本](https://raw.githubusercontent.com/kukubob/kingdee-keepalive/main/kingdee-keepalive.user.js)**，在油猴安装页确认安装。
3. 保存正在编辑的金蝶内容，刷新金蝶 HTML5 主页。
4. 右下角默认只显示一个不闪动的小圆点。点击圆点展开“保活中 · 剩余约 60 分钟”，再次点击收起。展开区域内有独立的暂停／恢复按钮。

如果安装链接只显示代码，请在油猴管理面板新建脚本，删除默认模板，粘贴链接中的完整代码并保存。若脚本没有运行，检查扩展的站点权限及用户脚本执行权限。

## 1.1.2：默认圆点，点击查看

- 默认只显示一个 10px 圆点，不闪烁、不显示倒计时；点击区域为 24px，方便操作。
- 点击圆点展开分钟级剩余时间，再点收起。展开/收起不影响后台保活。
- 展开时每分钟更新一次，不显示秒数；点击展开时读取一次最新值。
- 暂停／恢复使用展开区域内的独立按钮。
- 圆点使用低饱和颜色：绿色表示开启，灰色表示暂停或等待登录，红色表示离线或异常；没有动画。
- 每分钟检查一次，闲置达到 60 秒且满足重试间隔才请求保活；人工操作已重置计时时不重复请求。
- “保活中”表示运行模式，不表示服务器已确认续期。

## 工作方式

脚本仅在 `/k3cloud/html5/dform.aspx`、`formId=BOS_HtmlConsole` 的顶层页面运行，支持自建站点及不同端口。默认匹配任何使用该路径的站点，可在油猴设置中进一步限制到自己的金蝶站点。

已检查的金蝶前端资源版本为 `9.0.553.10`。其退出预警的“继续在线”分支使用：

```javascript
rootForm.fireCustomEventsNoData('Kingdee.BOS.LogOutPreFivePoint', '');
app.updateLastReqTime([{ actionname: 'idlewithhold' }], {});
```

脚本复用以上原生逻辑。检查到的源码中，`fireCustomEventsNoData` 将表单数据参数传为 `null`，不读取表单变更数据。脚本不模拟业务点击、不保存或提交单据，不读取或存储密码、Cookie 或登录链接；请求通过当前金蝶页面已有的会话发送。

暂停状态仅保存在当前标签页的 sessionStorage。脚本通过 GitHub Raw 地址检查后续更新。

## 验证与限制

- 已通过 JavaScript 语法检查及模拟环境行为检查：事件参数、闲置计时、定时调用、重复加载、暂停恢复、未登录、离线恢复、页面范围与生命周期。
- 1.0.0 已在真实页面对照人工打开只读功能及连续两次自动保活，均观察到闲置计时更新；相关请求返回 HTTP 200。
- 1.1.2 已通过语法及圆点展开/收起、分钟定时检查；尚未完成新版在真实金蝶中的长期空闲验收。
- 原生接口没有服务器续期确认回调。倒计时及重置检测仅反映前端闲置判断，不能据此断言服务器会话有效期。
- 金蝶升级后内部接口可能变化；显示“接口不可用”时需要重新检查版本。
- 电脑睡眠、浏览器冻结或丢弃标签页、断网、服务端强制到期、管理员踢出及异地登录仍可能导致退出。脚本不会自动重新登录，也不会拦截主动退出。

验收方法：保持电脑、浏览器及网络正常，在超过原来的闲置超时时间后，手动打开一个只读功能确认会话仍然可用。
